Bagian 2

            
Materi Dasar HTTP Request

        


        

            

                
Apa itu HTTP Request?

                

                    HTTP Request adalah permintaan yang dikirim oleh client kepada server.
                    Client dapat berupa browser, aplikasi mobile, frontend web, Postman,
                    atau dokumentasi interaktif seperti RapiDoc.
                

                

                    Dalam REST API, HTTP Request digunakan untuk meminta data, mengirim data,
                    memperbarui data, atau menghapus data dari server.
                

            


            

                
Client

                

                    
                    
HTTP Request

                

                
Server API

            

        


        

            

                1
                
Method

                

                    Method menunjukkan jenis operasi yang diminta oleh client.
                    Contohnya GET, POST, PUT, dan DELETE.
                

                
GET /api/mahasiswa.php

            


            

                2
                
Endpoint URL

                

                    Endpoint adalah alamat sumber daya API yang ingin diakses.
                    Setiap endpoint mewakili fungsi tertentu.
                

                
http://localhost/rapidoc-praktikum/api/mahasiswa.php

            


            

                3
                
Header

                

                    Header berisi informasi tambahan tentang request, seperti format data
                    dan token autentikasi.
                

                
Authorization: Bearer praktikum-token-123

            


            

                4
                
Body

                

                    Body berisi data yang dikirim ke server. Body biasanya digunakan pada
                    method POST dan PUT.
                

                
{
  "nim": "230101004",
  "nama": "Dewi Lestari",
  "prodi": "Informatika"
}

            

        


        

            

                
HTTP Method yang Digunakan pada Praktikum

                

                    Dalam praktikum ini, mahasiswa menggunakan empat method utama
                    untuk melakukan operasi CRUD.
                

            


            

                

                    GET
                    
Membaca Data

                    
Digunakan untuk mengambil daftar atau detail data mahasiswa.

                    GET /api/mahasiswa.php
                


                

                    POST
                    
Menambah Data

                    
Digunakan untuk mengirim data baru ke server.

                    POST /api/mahasiswa.php
                


                

                    PUT
                    
Memperbarui Data

                    
Digunakan untuk memperbarui data mahasiswa berdasarkan ID.

                    PUT /api/mahasiswa.php?id=1
                


                

                    DELETE
                    
Menghapus Data

                    
Digunakan untuk menghapus data mahasiswa berdasarkan ID.

                    DELETE /api/mahasiswa.php?id=1
                

            

        


        

            

                
Anatomi HTTP Request

                

                    Contoh berikut menunjukkan struktur request saat client menambahkan
                    data mahasiswa baru ke API.
                

            


            

                


// Request Line
POST /api/mahasiswa.php HTTP/1.1

// Headers
Host: localhost
Content-Type: application/json
Authorization: Bearer praktikum-token-123

// Body
{
  "nim": "230101004",
  "nama": "Dewi Lestari",
  "prodi": "Informatika",
  "angkatan": 2024,
  "email": "dewi@kampus.test"
}

                


                

                    

                        
Request Line

                        
Berisi method, endpoint, dan versi protokol HTTP.

                    

                    

                        
Headers

                        
Berisi metadata request, seperti format JSON dan token akses.

                    

                    

                        
Body

                        
Berisi data yang dikirim client kepada server.

                    

                

            

        


        

            

                
HTTP Response dari Server

                

                    Setelah menerima request, server akan mengirimkan response.
                    Response biasanya berisi status code dan data dalam format JSON.
                

            


            

                

                    200
                    
OK

                    
Request berhasil diproses.

                


                

                    201
                    
Created

                    
Data baru berhasil dibuat.

                


                

                    401
                    
Unauthorized

                    
Token tidak dikirim atau tidak valid.

                


                

                    404
                    
Not Found

                    
Data atau endpoint tidak ditemukan.

                


                

                    422
                    
Validation Error

                    
Data yang dikirim belum sesuai aturan validasi.

                


                

                    500
                    
Server Error

                    
Terjadi kesalahan pada server atau database.

Bagian 3

            
Alur Kerja REST API

        


        

            

                1
                

                    
Client Mengirim Request

                    

                        Client mengirim request ke endpoint API menggunakan
                        method GET, POST, PUT, atau DELETE.
                    

                

            


            

                2
                

                    
API Mengecek Token

                    

                        Server membaca header Authorization dan memvalidasi
                        Bearer Token.
                    

                

            


            

                3
                

                    
API Mengakses Database

                    

                        Server menjalankan query ke MySQL menggunakan PDO.
                    

                

            


            

                4
                

                    
Server Mengirim Response JSON

                    

                        Server mengembalikan data dalam format JSON dengan
                        HTTP status code yang sesuai.
